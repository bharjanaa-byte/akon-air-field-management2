# Akon Air Field Management — prototype

This is a standalone Progressive Web App prototype. It stores test jobs in the browser on the device currently being used.

## Review locally

Open the folder with any simple local web server, then visit its local address in a browser. Do not open `index.html` directly from Files: service workers and installation require a web address.

## Install on iPhone

Upload this folder to a secure host (for example, GitHub Pages, Netlify, or Cloudflare Pages). Open the resulting `https://` address in Safari, tap Share, then **Add to Home Screen**.

## Prototype coverage

- Akon Air branding placeholder and installable PWA settings
- Dashboard, job list, payment tracking, and calendar
- GoLine and Akon Air job flows
- Required GoLine work order, rate-sheet selection, and extras
- Installation-specific photo/test categories
- Print-ready completion-report preview: one summary page plus one page per photo/test category, labeled with work order and page number

## Before production

Replace the placeholder logo/icon with the supplied Akon Air artwork, confirm every GoLine rate, and add cloud-backed accounts/storage before multiple technicians use it.
